# برنامه مالی خانواده

اپ اندروید برای مدیریت پول یک خانواده: حساب‌ها، هزینه و درآمد، طلب و بدهی، وام و اقساط، چک‌ها و بودجه هر عضو خانواده.
تراکنش‌ها از پیامک بانک‌ها خودکار خوانده می‌شوند و مانده هر پیامک با مانده برنامه تطبیق داده می‌شود.

## نصب

هر بار که کدی به شاخه `main` اضافه شود، GitHub فایل نصب (APK) را می‌سازد و در بخش
[Releases](../../releases) می‌گذارد. فایل را روی گوشی دانلود و نصب کنید.

## امکانات نسخه اول

- تعریف حساب بانکی، کارت، نقد، صندوق، طلا و ارز؛ فهرست همه بانک‌های ایران
- خواندن خودکار پیامک بانک، تأیید با یک لمس، یادگیری دسته و عضو از روی فروشگاه
- تطبیق مانده هر پیامک با مانده برنامه و اصلاح خودکار اختلاف (با فهرست قابل بازبینی)
- اعضای خانواده با بودجه ماهانه و هشدار ۸۰٪ و ۱۰۰٪
- طلب و بدهی با افراد، وام با جدول اقساط، چک دریافتی و پرداختی، پرداخت‌های تکراری
- داشبورد، گزارش ماهانه، روند ۶ ماه، مقایسه با میانگین ماه‌های قبل
- تقویم شمسی، واحد تومان یا ریال، قفل با اثر انگشت، پایگاه داده رمزشده، پشتیبان رمزدار و خروجی اکسل

## امضای ثابت برای به‌روزرسانی

برای این‌که نسخه‌های بعدی روی نسخه قبلی نصب شوند و اطلاعات نپرد، چهار secret در تنظیمات مخزن لازم است:
`SIGNING_KEYSTORE_BASE64`، `SIGNING_STORE_PASSWORD`، `SIGNING_KEY_ALIAS`، `SIGNING_KEY_PASSWORD`.

## ساختار کد

- `core/`: منطق خالص Kotlin با تست (تقویم شمسی، خواندن پیامک بانک، تطبیق مانده، اقساط). اجرا: `./gradlew -PcoreOnly=true :core:test`
- `app/`: اپ اندروید (Jetpack Compose، Room با SQLCipher، WorkManager)
